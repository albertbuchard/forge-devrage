# Notices

`forge-devrage` was built after inspecting the public `devrage@0.0.4` npm
package, which is MIT licensed and describes itself as a tool to count swearing
in coding-agent conversations. The `forge-devrage` implementation keeps the
same local-first spirit and multi-adapter product shape while adding structured
conversation summaries, day filtering, and Forge integration APIs.

No private conversation logs, report outputs, or local database files are part
of this package.
